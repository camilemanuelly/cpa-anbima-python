# CPA ANBIMA + Python.

Repositório dedicado aos meus estudos ativos para a certificação **CPA (ANBIMA)**, unindo teoria do mercado financeiro com lógica de programação em Python. 

A metodologia consiste em transformar cada tema da apostila em desafios práticos de código, simulando cenários econômicos, cálculos financeiros e regras de negócio.

## Progresso por Módulos

### `01-mercado-financeiro`
* **`01_fluxo_renda_circular.py`**: Simulação mensal da circulação de capital entre Famílias, Empresas e Governo, aplicando alíquotas de impostos, propensão ao consumo e gastos públicos.
  * **Conceitos de Python aplicados:** Variáveis e operações aritméticas, estruturas de repetição (`for`), atualização de estado/acumuladores e formatação de saída com `f-strings`.

---

## Como executar os scripts

1. Clone o repositório:
   ```bash
   git clone https://github.com/camilemanuelly/cpa-anbima-python.git
   ```
2. Acesse a pasta do projeto e execute o arquivo desejado (requer Python 3+):
   ```bash
   python 01-mercado-financeiro/01_fluxo_renda_circular.py
   ```
